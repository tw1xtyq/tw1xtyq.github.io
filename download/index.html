Сборка не подписана платным сертификатом, поэтому Windows может предупредить о неизвестном издателе.

  2. Нажмите «Выполнить в любом случае»

Как проверить файл

Откройте PowerShell в папке загрузки и выполните команду. Результат должен совпасть с SHA-256 выше.

Get-FileHash .\Skvoz-Setup-1.11.5.exe -Algorithm SHA256
