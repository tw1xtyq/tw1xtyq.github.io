Безопасность

Что Skvoz делает на вашем компьютере

Программе с правами администратора нужно доверять. Здесь написано, на чём это доверие держится и где его границы.

Какие данные собирает приложение

Никаких: в Skvoz нет телеметрии, аналитики и учётных записей. Настройки хранятся только на вашем компьютере. Отчёт для баг-репорта создаётся по вашей команде, сохраняется файлом и никуда не отправляется сам. Имя пользователя и домашняя папка в нём скрыты.

Зачем права администратора

Обход работает через драйвер WinDivert, который перехватывает сетевые пакеты, а VPN создаёт сетевой адаптер и службу Windows. Без прав администратора система этого не разрешит.

Откуда берутся сборки и компоненты

  • Релизы собираются на GitHub Actions из открытого кода, а у каждого файла есть SHA-256.
  • Zapret и другие компоненты используются без изменений. Их авторы и лицензии перечислены на странице «Сторонние проекты».
  • Skvoz сверяет SHA-256 при обновлении wgcf, запасного инструмента регистрации WARP.

Что важно понимать

  • Сборки не подписаны. Поэтому появляется SmartScreen, а файл стоит проверять по SHA-256.
  • Обход не шифрует трафик и не скрывает вас. Он только меняет то, как пакеты выглядят для провайдера.
  • VPN передаёт трафик через сервер. Вы доверяете его владельцу: Cloudflare для WARP или тому, кто выдал ваш конфиг.
  • Регистрация WARP неофициальная. Cloudflare может её ограничить.
  • Skvoz не связан с авторами компонентов и с Cloudflare. Это независимый проект.

Как устроен этот сайт

  • Это статические файлы: сервера приложений, базы данных, форм и учётных записей нет, поэтому украсть здесь нечего.
  • Нет cookies, счётчиков и рекламы. Шрифты лежат на самом сайте, браузер не обращается к сторонним сервисам.
  • Строгая политика CSP запрещает внешние скрипты, инлайн-код и сетевые запросы из страниц.
  • Ссылки на файлы проверяются при сборке: на страницу попадают только адреса релизов репозитория Skvoz.

Нашли уязвимость?

Не публикуйте её в открытом доступе. Сообщите через раздел Security на GitHub.
